# Unit 5 Practice and a Multi-Unit Site — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add AMSCO Unit 5 (*Revolutions, c. 1750–1900*) as a second practice page with Unit 4's formats and checks, behind a site index, without changing anything a student sees in Unit 4.

**Architecture:** Each unit owns a folder under `data/` (`unit.json` plus the four bank files and `research/`). `loadData` reads a unit folder, `validate` takes its topics, year range and minimums from `data.unit`, and `build` writes `dist/<unit>/index.html` and `local.html` per unit plus a landing page that forwards old `#code` links to Unit 4. A headless-Chrome checker (`tools/check-page.js`) proves each page works and that Unit 4 renders the same text as before the restructure. Unit 5's content goes through the Unit 4 pipeline (research, mechanical source check, verification, writing, accuracy review) with Sonnet agents and explicit cost caps.

**Tech Stack:** Node 22+ (running 26), built-ins only: `node:test`, `fetch`, `node:crypto`, `node:child_process`. No npm dependencies. Plain HTML/CSS/JS. Local Google Chrome for the page check only (not CI).

**Spec:** `docs/superpowers/specs/2026-10-15-unit-5-design.md` (binding). It builds on `docs/superpowers/specs/2026-10-13-amsco-unit4-dbq-design.md`; the Unit 4 plan `docs/superpowers/plans/2026-10-13-amsco-unit4-dbq.md` is the model for the content tasks (9–13 here adapt its Tasks 6–11 and Amendment A). Read the Unit 5 spec first, then this plan.

## Spec gaps found while planning, and how this plan resolves them

1. **Example code in `unit.json`.** The spec's `unit.json` has no place for the sample code shown in the "Open a code" box's placeholder and in the "That code isn’t valid. Codes look like dbq.silver-trade.k2x9q1." message. Both are hard-coded to a Unit 4 prompt and would be wrong on Unit 5. The plan adds one required field, `exampleCode` (Unit 4: `dbq.silver-trade.k2x9q1`, so its text is unchanged; Unit 5: `dbq.enlightenment-revolutions.k2x9q1`).
2. **`topicsWithItems` sorts topics as strings**, so with Unit 5 the message "Topics with DBQs: …" would list `5.10` before `5.2`. Task 3 sorts numerically (Unit 4's output is unchanged: its codes are single-digit).
3. **Browser storage is shared by both units on `zrrbite.github.io`** (same origin). A topic selection saved by Unit 4 would otherwise be restored on Unit 5. Task 3 moves the restore logic into `store.js` as `selectTopics`, which falls back to all topics when nothing saved applies. Storage keys stay the same so Unit 4 students keep their saved filter.
4. **`candidates.js merge|promote` write the bank**, so "defaults to every unit" would let a stray `promote` rewrite Unit 4's `documents.json`. They require `--unit`; `check-refs`, `check-sources` and `validate` keep the every-unit default.
5. **The spec gives DBQ prompt ids, topics and groups but not the prompt wording.** The wording is fixed in Task 9 (a table the writing agents copy); change it there if you want different wording.
6. **Opening `dist/index.html` from disk**: the spec's links go to `unit-N/`, which is a directory listing on `file://`. The landing page's script points the links at `unit-N/local.html` when `location.protocol` is `file:` (and forwards `#code` the same way).

## Review Focus

Failure modes the spec implies but no happy-path test exercises, most likely first. Each is pinned in the task named.

1. **Old root links** (`/#dbq.silver-trade.1`, an empty hash, a lone `#`, a hash such as `#javascript:alert(1)`): a code forwards to `unit-4/#code`; an empty or lone `#` stays on the index; the target is always built from the fixed prefix, so a hash can never become a URL scheme. Pinned in Task 4 (`test/landing.test.js`) and checked in Chrome in Task 7.
2. **Missing or malformed `unit.json`** (file absent, bad JSON, a field missing or wrong type, a topic key from another unit, `id` not matching its folder): `validate` and `build` report the field and file in a plain message, never a stack trace or a half-built page. Pinned in Task 2 (`test/validate.test.js`, `test/load-data.test.js`).
3. **Topic `5.10` and ten chips**: ordering in "Topics with DBQs: …", the `topic-5-10` checkbox id, and the saved-filter restore. The ordering and the restore are pinned in Task 3 (`test/sampler.test.js`, `test/store.test.js`); the `topic-5-10` checkbox is clicked by `check-page` on Unit 5 in Task 13.
4. **A saved topic filter or recents written by the other unit** (same site, same storage keys) or junk/absent storage: the page starts with all topics on. Pinned in Task 3 (`test/store.test.js`).
5. **Unit title or period with `&`, `<` or quotes**, and a Britannica reference run that gets rate-limited: titles are HTML-escaped in the template and landing page (Task 3, Task 4), and Wayback requests are paced even across retries (Task 6).

```js
// Drives a local headless Chrome for the page checks (tools/check-page.js, tools/snapshot-render.js).
// Chrome is not installed in CI, so nothing in `npm test` launches it.
import { execFile } from 'node:child_process';
import { createHash } from 'node:crypto';
import { mkdtemp, readFile, rm, writeFile } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import path from 'node:path';
import { fileURLToPath, pathToFileURL } from 'node:url';
import { promisify } from 'node:util';

const execFileAsync = promisify(execFile);
const HERE = path.dirname(fileURLToPath(import.meta.url));
export const CHROME = process.env.CHROME ?? '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome';

export const sha256 = (text) => createHash('sha256').update(text).digest('hex');

// The page's DOM after its scripts have run, as Chrome serialises it.
export async function dumpDom(url) {
  const profile = await mkdtemp(path.join(tmpdir(), 'chrome-profile-'));
  try {
    const { stdout } = await execFileAsync(
      CHROME,
      ['--headless=new', `--user-data-dir=${profile}`, '--allow-file-access-from-files', '--virtual-time-budget=30000', '--dump-dom', url],
      { maxBuffer: 256 * 1024 * 1024, timeout: 180_000 },
    );
    return stdout;
  } finally {
    await rm(profile, { recursive: true, force: true });
  }
}

// The harness writes its result as base64 JSON into <pre id="result">. Base64, so that entities and
// markup in the page text cannot be mangled by DOM serialisation; "running..." is not base64.
export function decodeResult(dom) {
  const match = /<pre id="result">([A-Za-z0-9+/=]+)<\/pre>/.exec(dom);
  if (!match) throw new Error('the page harness did not finish: <pre id="result"> holds no result');
  return JSON.parse(Buffer.from(match[1], 'base64').toString('utf8'));
}

// Copies tools/page-harness.html next to local.html (it loads it in an iframe), runs it in Chrome
// and returns {texts, results}. config: { codes: string[], checks: boolean }.
export async function runHarness(localHtml, config) {
  const template = await readFile(path.join(HERE, 'page-harness.html'), 'utf8');
  const harness = path.join(path.dirname(localHtml), 'harness.html');
  const settings = { ...config, page: path.basename(localHtml) };
  await writeFile(harness, template.replace('__CONFIG__', () => JSON.stringify(settings)));
  return decodeResult(await dumpDom(pathToFileURL(harness).href));
}

export function snapshotOf(texts) {
  return { codes: Object.fromEntries(Object.entries(texts).map(([code, text]) => [code, { sha256: sha256(text), chars: text.length }])) };
}

// Problems found comparing freshly rendered texts with a stored snapshot; [] means identical.
export function compareSnapshot(texts, snapshot) {
  const problems = [];
  for (const [code, expected] of Object.entries(snapshot.codes)) {
    const text = texts[code];
    if (typeof text !== 'string') problems.push(`${code}: nothing was rendered`);
    else if (sha256(text) !== expected.sha256) problems.push(`${code}: rendered text changed (${text.length} characters now, ${expected.chars} in the snapshot)`);
  }
  return problems;
}
```

```js
#!/usr/bin/env node
// Captures or compares the rendered text of a built unit page for a fixed list of share codes.
//   node tools/snapshot-render.js <local.html> --write <snapshot.json>     capture the codes in SNAPSHOT_CODES
//   node tools/snapshot-render.js <local.html> --compare <snapshot.json>   compare with a stored snapshot
//   add --texts <file.json> to also save the full rendered texts, for diffing
// Needs local Chrome (see tools/chrome.js).
import { readFile, writeFile } from 'node:fs/promises';
import path from 'node:path';
import { pathToFileURL } from 'node:url';
import { compareSnapshot, runHarness, snapshotOf } from './chrome.js';

// Three DBQ draws, a DBQ drawn from a short seed, a seed spelled with letters, one SAQ and one MCQ set.
export const SNAPSHOT_CODES = [
  'dbq.silver-trade.1',
  'dbq.exploration-causes.2',
  'dbq.east-asia-responses.zz9',
  'dbq.challenges-to-state-power.k2x9q1',
  'saq.henry-navigator-motives',
  'mcq.acosta-mercury-silver',
];

async function main(argv) {
  const flag = (name) => {
    const at = argv.indexOf(name);
    return at >= 0 ? argv[at + 1] : null;
  };
  const [page] = argv;
  const write = flag('--write');
  const compare = flag('--compare');
  if (!page || page.startsWith('--') || (!write && !compare)) {
    throw new Error('usage: node tools/snapshot-render.js <local.html> (--write <file> | --compare <file>) [--texts <file>]');
  }
  const codes = compare ? Object.keys(JSON.parse(await readFile(compare, 'utf8')).codes) : SNAPSHOT_CODES;
  const { texts } = await runHarness(path.resolve(page), { codes, checks: false });
  const missing = codes.filter((code) => typeof texts[code] !== 'string');
  if (missing.length > 0) throw new Error(`nothing rendered for ${missing.join(', ')}${texts.error ? `: ${texts.error}` : ''}`);
  if (flag('--texts')) await writeFile(flag('--texts'), `${JSON.stringify(texts, null, 2)}\n`);
  if (write) {
    await writeFile(write, `${JSON.stringify(snapshotOf(Object.fromEntries(codes.map((code) => [code, texts[code]]))), null, 2)}\n`);
```

```js
import { readdir, readFile } from 'node:fs/promises';
import path from 'node:path';

export const DATA_FILES = ['documents', 'dbqs', 'saqs', 'mcqs'];
const UNIT_FOLDER = /^unit-(\d+)$/;

async function readJson(file) {
  try {
    return JSON.parse(await readFile(file, 'utf8'));
  } catch (error) {
    throw new Error(`${file}: ${error.message}`);
  }
}

// Reads one unit's folder. A missing unit.json leaves data.unit undefined so that validate() can report it.
export async function loadData(dir) {
  const data = {};
  const unitFile = path.join(dir, 'unit.json');
  try {
    data.unit = JSON.parse(await readFile(unitFile, 'utf8'));
  } catch (error) {
    if (error.code !== 'ENOENT') throw new Error(`${unitFile}: ${error.message}`);
  }
  for (const name of DATA_FILES) data[name] = await readJson(path.join(dir, `${name}.json`));
  return data;
}

// The unit folders under data/, in numeric order (unit-4, unit-5, unit-10).
export async function listUnits(dataRoot) {
  const entries = await readdir(dataRoot, { withFileTypes: true });
  return entries
    .filter((entry) => entry.isDirectory() && UNIT_FOLDER.test(entry.name))
    .map((entry) => entry.name)
    .sort((a, b) => Number(UNIT_FOLDER.exec(a)[1]) - Number(UNIT_FOLDER.exec(b)[1]));
}

// Every unit, or just `only`: [{id, dir}].
export async function selectUnits(dataRoot, only = null) {
  const ids = await listUnits(dataRoot);
  if (only !== null && !ids.includes(only)) throw new Error(`no such unit "${only}" (known: ${ids.join(', ') || 'none'})`);
  return (only === null ? ids : [only]).map((id) => ({ id, dir: path.join(dataRoot, id) }));
}

// loadData for a {id, dir} from selectUnits, refusing a unit.json that names a different unit.
export async function loadUnit({ id, dir }) {
  const data = await loadData(dir);
  if (data.unit && typeof data.unit === 'object' && data.unit.id !== id) {
    throw new Error(`${path.join(dir, 'unit.json')}: id is "${data.unit.id}" but the folder is ${id}`);
  }
  return data;
}

// Splits "--unit <id>" out of a command line: { unit: id | null, args: the rest }.
export function takeUnit(argv) {
  const at = argv.indexOf('--unit');
  if (at < 0) return { unit: null, args: [...argv] };
  const unit = argv[at + 1];
  if (!unit || unit.startsWith('--')) throw new Error('--unit needs a unit id such as unit-5');
  return { unit, args: [...argv.slice(0, at), ...argv.slice(at + 2)] };
}

// A file argument given relative to a unit's folder; absolute paths are used as they are.
export const inUnit = (dir, file) => (path.isAbsolute(file) ? file : path.join(dir, file));
```

```js
// Checks unit.json field by field. Returns true when it is sound enough to validate the rest against.
export function checkUnit(unit, fail) {
  let ok = true;
  const bad = (field, message) => {
    ok = false;
    fail('unit.json', `${field}: ${message}`);
  };
  if (unit === null || typeof unit !== 'object' || Array.isArray(unit)) {
    fail('unit.json', 'missing or not a JSON object');
    return false;
  }
  const numberOk = Number.isInteger(unit.number) && unit.number >= 1;
  if (!numberOk) bad('number', 'must be a whole number from 1');
  const expectedId = numberOk ? `unit-${unit.number}` : 'unit-N';
  if (typeof unit.id !== 'string' || !(numberOk ? unit.id === expectedId : /^unit-\d+$/.test(unit.id))) bad('id', `must look like "${expectedId}"`);
  if (!nonEmpty(unit.title)) bad('title', 'is required');
  if (!nonEmpty(unit.period)) bad('period', 'is required');
  if (!Array.isArray(unit.years) || unit.years.length !== 2 || !unit.years.every(Number.isInteger) || unit.years[0] >= unit.years[1]) {
    bad('years', 'must be two whole numbers, earliest first');
  }
  if (unit.topics === null || typeof unit.topics !== 'object' || Array.isArray(unit.topics) || Object.keys(unit.topics).length === 0) {
    bad('topics', 'must be an object from topic code to label, with at least one topic');
  } else {
    for (const [code, label] of Object.entries(unit.topics)) {
      if (numberOk && !new RegExp(`^${unit.number}\\.\\d+$`).test(code)) bad('topics', `"${code}" must start with "${unit.number}."`);
      else if (!numberOk && !/^\d+\.\d+$/.test(code)) bad('topics', `"${code}" must look like 5.1`);
      if (!nonEmpty(label)) bad('topics', `"${code}" needs a label`);
    }
  }
  if (unit.minimums === null || typeof unit.minimums !== 'object' || Array.isArray(unit.minimums)) {
    bad('minimums', 'must be an object');
  } else {
    for (const key of MINIMUM_KEYS) {
      if (!Number.isInteger(unit.minimums[key]) || unit.minimums[key] < 1) bad(`minimums.${key}`, 'must be a positive whole number');
    }
  }
  if (unit.shareBase !== null && !(typeof unit.shareBase === 'string' && /^https:\/\/\S+$/.test(unit.shareBase))) bad('shareBase', 'must be null or an https link');
  if (typeof unit.exampleCode !== 'string' || !EXAMPLE_CODE.test(unit.exampleCode)) bad('exampleCode', 'must look like dbq.some-prompt.k2x9q1');

}
```

```js
export const escapeHtml = (value) => String(value).replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');

// Replaces every occurrence of marker. Uses split/join, not String.replace, so "$&" in the value stays literal.
export function fill(template, marker, value) {
  if (!template.includes(marker)) throw new Error(`the template is missing ${marker}`);
```

```js
    throw new Error(`${name}: only "import { … } from './x.js';" and "export function/const" are supported`);
  }
  return out;
}

// JSON that is safe inside <script type="application/json">: no "</script>", no raw line separators.
export function jsonForHtml(value) {
  return JSON.stringify(value).replace(/</g, '\\u003c').replace(/\u2028/g, '\\u2028').replace(/\u2029/g, '\\u2029');
}

// What the page needs from a unit's bank at run time.
export function runtimeBank(data, shareBase) {
  const documents = data.documents.map(({ original, verified, verifiedBy, verifiedNote, ...shown }) => shown);
  const { id, number, title, period, topics, exampleCode } = data.unit;
  return {
    config: { shareBase: shareBase ?? null },
    unit: { id, number, title, period, topics, exampleCode },
    documents,
    dbqs: data.dbqs,
    saqs: data.saqs,
    mcqs: data.mcqs,
  };
}

// Unit text goes in first, then styles, script and finally the bank, so that markers in later text can never be filled.
export function renderPage(template, { styles, script, bank }) {
  const { unit } = bank;
  let page = fill(template, '__UNIT_NUMBER__', escapeHtml(unit.number));
  page = fill(page, '__UNIT_TITLE__', escapeHtml(unit.title));
  page = fill(page, '__UNIT_PERIOD__', escapeHtml(unit.period));
  page = fill(page, '__EXAMPLE_CODE__', escapeHtml(unit.exampleCode));
  page = fill(page, '/*STYLES*/', styles);
  page = fill(page, '/*SCRIPT*/', script);
  return fill(page, '__BANK__', jsonForHtml(bank));
}

const wrapAsDocument = (page) => [
  '<!doctype html>',
  '<html lang="en">',
  '<head>',
  '<meta charset="utf-8">',

  '</head>',
  '<body>',
  page,
  '</body>',
  '</html>',
  '',
].join('\n');

export async function build({ dataRoot = path.join(ROOT, 'data'), outDir = path.join(ROOT, 'dist'), only = null } = {}) {
  const loaded = [];
  for (const entry of await selectUnits(dataRoot, only)) {
    const data = await loadUnit(entry);
    const errors = validate(data);
    if (errors.length) throw new Error(`${entry.id}: the question bank has ${errors.length} problem(s):\n${errors.join('\n')}`);
    loaded.push({ id: entry.id, data });
  }
  if (loaded.length === 0) throw new Error(`no unit folders found under ${dataRoot}`);
  const src = (name) => readFile(path.join(ROOT, 'src', name), 'utf8');
  const parts = await Promise.all(MODULES.map(async (name) => `// ${name}\n${stripModuleSyntax(await src(name), name)}`));
  const script = parts.join('\n');
  if (/<\/script/i.test(script)) throw new Error('src/*.js must not contain "</script"');
  const template = await src('index.html');
  const styles = await src('styles.css');
  const units = [];
  for (const { id, data } of loaded) {
    const page = renderPage(template, { styles, script, bank: runtimeBank(data, data.unit.shareBase) });
    const folder = path.join(outDir, id);
    await mkdir(folder, { recursive: true });
    const indexPath = path.join(folder, 'index.html');
    const localPath = path.join(folder, 'local.html');
    await writeFile(indexPath, page);
    await writeFile(localPath, wrapAsDocument(page));
    units.push({ id, indexPath, localPath, bytes: Buffer.byteLength(page) });
  }
  return { units };
}
```

```js
// The site's landing page: one card per unit, plus a script that forwards old root links
// carrying a #code to Unit 4 (only Unit 4 existed when those links were shared).
import { escapeHtml, fill } from './html.js';

export const UNIT_HOME = 'unit-4';

// Plain browser JavaScript. Served over http(s) the links go to unit-N/ and the forward to unit-4/#code;
// from disk (file:) a folder has no index, so both go to unit-N/local.html. The destination is built from
// UNIT_HOME and the hash only, so a hash can never choose a different URL scheme or host.
export const FORWARD_SCRIPT = `
var UNIT_HOME = '${UNIT_HOME}';
function unitUrl(unit) { return location.protocol === 'file:' ? unit + '/local.html' : unit + '/'; }
var links = document.querySelectorAll('a[data-unit]');
for (var i = 0; i < links.length; i++) links[i].setAttribute('href', unitUrl(links[i].getAttribute('data-unit')));
if (location.hash.length > 1) location.replace(unitUrl(UNIT_HOME) + location.hash);
`;

const count = (n, one, many = `${one}s`) => `${n} ${n === 1 ? one : many}`;

export function unitCard({ unit, counts }) {
  const line = [
    count(counts.dbqs, 'DBQ'),
    count(counts.saqs, 'short-answer question'),
    count(counts.mcqs, 'multiple-choice set'),
    count(counts.documents, 'document'),
  ].join(' · ');
  const id = escapeHtml(unit.id);
  return `<li class="unit-card"><a href="${id}/" data-unit="${id}">`
    + `<span class="unit-name">Unit ${escapeHtml(unit.number)} · ${escapeHtml(unit.title)}</span>`
    + `<span class="unit-period">${escapeHtml(unit.period)}</span>`
    + `<span class="unit-counts">${escapeHtml(line)}</span></a></li>`;
}

// units: [{ unit, counts: { documents, dbqs, saqs, mcqs } }]
export function landingPage(template, styles, units) {
  let page = fill(template, '/*STYLES*/', styles);
  page = fill(page, '__UNITS__', units.map(unitCard).join('\n'));
  return fill(page, '/*FORWARD*/', FORWARD_SCRIPT);
}
```

```js
//   node tools/candidates.js merge   --unit unit-5   research/cluster-*.json -> research/candidates.json
//   node tools/candidates.js promote --unit unit-5   verified candidates -> documents.json (dropped ones are listed)

const byId = (a, b) => (a.id < b.id ? -1 : a.id > b.id ? 1 : 0);

export function mergeClusters(clusters) {
  const kept = new Map();
  const conflicts = [];
  for (const { cluster, documents } of clusters) {
    for (const doc of documents) {
      const prev = kept.get(doc.id);
      if (!prev) kept.set(doc.id, { cluster, doc: { ...doc, verified: false } });
      else if (prev.doc.text !== doc.text || prev.doc.sourceUrl !== doc.sourceUrl) {
        conflicts.push(`${doc.id}: cluster ${cluster} has a different version; kept the one from cluster ${prev.cluster}`);
      }
    }
  }
  return { documents: [...kept.values()].map((k) => k.doc).sort(byId), conflicts };
}

export function promote(candidates) {
  const undecided = candidates.filter((d) => d.verified !== true && !d.dropped).map((d) => d.id);
  if (undecided.length) throw new Error(`Not yet verified or dropped: ${undecided.join(', ')}`);
  const documents = candidates.filter((d) => d.verified === true && !d.dropped).map(({ dropped, ...doc }) => doc).sort(byId);
  const dropped = candidates.filter((d) => d.dropped).map((d) => `${d.id}: ${d.dropped}`);
  return { documents, dropped };
}

const writeJson = (file, value) => writeFile(file, `${JSON.stringify(value, null, 2)}\n`);

export async function mergeUnit(dir) {

  const candidates = path.join(research, 'candidates.json');
  if (await access(candidates).then(() => true, () => false)) {
    throw new Error('research/candidates.json already exists; delete it to merge again (this discards verification marks)');
  }
  const files = (await readdir(research)).filter((f) => /^cluster-[a-z]+\.json$/.test(f)).sort();
  if (files.length === 0) throw new Error('research/ has no cluster-*.json files');
  const clusters = await Promise.all(files.map(async (f) => JSON.parse(await readFile(path.join(research, f), 'utf8'))));
  const { documents, conflicts } = mergeClusters(clusters);

  await writeJson(path.join(dir, 'documents.json'), documents);
  return { documents: documents.length, dropped };
}
```

```js
const WAYBACK = /^https:\/\/web\.archive\.org\//;
export const WAYBACK_GAP_MS = 1000;

// Wraps a fetcher so Wayback Machine requests (the index, the captures, and every retry of either)
// start at least gapMs apart. Without this the Unit 4 release run was rate-limited (HTTP 429) after
// about 116 links. Other hosts are not slowed. Start times are reserved before waiting, so callers
// that overlap still come out spaced.
export function paceWayback(fetcher, { gapMs = WAYBACK_GAP_MS, now = Date.now, wait = sleep } = {}) {
  let nextFree = -Infinity;
  return async (url) => {
    if (WAYBACK.test(url)) {
      const start = Math.max(now(), nextFree);
      nextFree = start + gapMs;
      if (start > now()) await wait(start - now());
    }
    return fetcher(url);
  };
}
```

- [ ] **Step 3: Write `tools/check-page.js`**

```js
#!/usr/bin/env node
// Builds every unit (or one) and checks each built page in headless Chrome:
//   - the 34 page checks (load, codes, scoring guides, filters, drills, timer, 400px layout, every code in the bank);
//   - when test/fixtures/<unit>-render.json exists, that the rendered text for its codes is unchanged;
//   - for a full run, that the landing page forwards /#dbq.silver-trade.1 to Unit 4.
// Usage: npm run check-page [-- --unit unit-5] [--no-build]
// Needs local Chrome (see tools/chrome.js). CI does not run it.
import { readFile } from 'node:fs/promises';
import path from 'node:path';
import { fileURLToPath, pathToFileURL } from 'node:url';
import { build } from './build.js';
import { compareSnapshot, dumpDom, runHarness } from './chrome.js';
import { UNIT_HOME } from './landing.js';
import { selectUnits, takeUnit } from './load-data.js';

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..');
export const EXPECTED_CHECKS = 34;
const LANDING_CODE = 'dbq.silver-trade.1';

// Everything wrong in a harness run: failed or crashed checks, and a run that did not reach all 34.
export function problemsIn(results) {
  const problems = results.filter((line) => !line.startsWith('PASS'));
  const ran = results.filter((line) => /^(PASS|FAIL) /.test(line)).length;
  if (ran !== EXPECTED_CHECKS) problems.push(`expected ${EXPECTED_CHECKS} checks, ${ran} ran`);
  return problems;
}

async function readSnapshot(id) {
  try {
    return JSON.parse(await readFile(path.join(ROOT, 'test', 'fixtures', `${id}-render.json`), 'utf8'));
  } catch (error) {
    if (error.code === 'ENOENT') return null;
    throw error;
  }
}

async function checkUnitPage(id, dist) {
  const snapshot = await readSnapshot(id);
  const { texts, results } = await runHarness(path.join(dist, id, 'local.html'), { codes: snapshot ? Object.keys(snapshot.codes) : [], checks: true });
  const problems = problemsIn(results);
  if (texts.error) problems.push(`harness: ${texts.error}`);
  console.log(id);
  for (const line of results) console.log(`  ${line}`);
  if (snapshot && !texts.error) {
    const changed = compareSnapshot(texts, snapshot);
    if (changed.length === 0) console.log(`  PASS  rendered text unchanged for ${Object.keys(snapshot.codes).length} codes`);
    else for (const line of changed) console.log(`  FAIL  ${line}`);
    problems.push(...changed);
  }
  return problems.length;
}

async function checkLanding(dist) {
  const url = `${pathToFileURL(path.join(dist, 'index.html')).href}#${LANDING_CODE}`;
  const shown = new RegExp(`<code id="current-code">${LANDING_CODE.replace(/\./g, '\\.')}</code>`).test(await dumpDom(url));
  console.log(`landing\n  ${shown ? 'PASS' : 'FAIL'}  /#${LANDING_CODE} forwards to ${UNIT_HOME} and opens that code`);
  return shown ? 0 : 1;
}

async function main(argv) {
  const { unit, args } = takeUnit(argv);
  const dist = path.join(ROOT, 'dist');
  if (!args.includes('--no-build')) await build({ outDir: dist, only: unit });
  const ids = (await selectUnits(path.join(ROOT, 'data'), unit)).map((u) => u.id);
  let problems = 0;
  for (const id of ids) problems += await checkUnitPage(id, dist);
  if (unit === null && ids.includes(UNIT_HOME)) problems += await checkLanding(dist);
  console.log(problems === 0 ? '\nAll page checks passed.' : `\n${problems} problem(s).`);
  if (problems) process.exit(1);
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  main(process.argv.slice(2)).catch((error) => {
    console.error(error.message);
    process.exit(1);
  });
}
```

- [ ] **Step 2: Write `tools/apply-edits.js`**

```js
#!/usr/bin/env node
// Applies reviewer edits to a unit's DBQs, SAQs and MCQ sets. All-or-nothing: if any edit does not
// apply, nothing is written.
//   node tools/apply-edits.js --unit unit-5 research/review-edits.json [--dry]
// An edit is { file: "dbqs"|"saqs"|"mcqs" (".json" optional), id, path: "notes.thesis.1", old, new }.
// "path" is dotted, numbers index arrays. "old" must equal the current text exactly, so a stale or
// mistyped edit is refused, never guessed at.
import { readFile, writeFile } from 'node:fs/promises';
import path from 'node:path';
import { fileURLToPath, pathToFileURL } from 'node:url';
import { inUnit, selectUnits, takeUnit } from './load-data.js';

const DATA_ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..', 'data');
const FILES = ['dbqs', 'saqs', 'mcqs'];

export function applyEdit(bank, edit) {
  const name = String(edit.file).replace(/\.json$/, '');
  if (!FILES.includes(name)) throw new Error(`edit for ${edit.id}: file must be dbqs, saqs or mcqs, not "${edit.file}"`);
  const item = bank[name].find((x) => x.id === edit.id);
  if (!item) throw new Error(`${name}: no item with id ${edit.id}`);
  const parts = String(edit.path).split('.');
  let node = item;
  for (const part of parts.slice(0, -1)) {
    node = node?.[part];
    if (node === null || typeof node !== 'object') throw new Error(`${name} ${edit.id}: nothing at path ${edit.path}`);
  }
  const last = parts[parts.length - 1];
  if (typeof node[last] !== 'string') throw new Error(`${name} ${edit.id}: ${edit.path} is not a text value`);
  if (node[last] !== edit.old) throw new Error(`${name} ${edit.id}: ${edit.path} no longer reads as the edit expects`);
  if (typeof edit.new !== 'string' || edit.new === edit.old) throw new Error(`${name} ${edit.id}: ${edit.path}: new text must differ from the old text`);
  node[last] = edit.new;
}

// Applies every edit to the unit folder `dir`; returns { applied, files } (the files that changed).
export async function applyEdits(dir, edits, { dry = false } = {}) {
  const bank = {};
  for (const name of FILES) bank[name] = JSON.parse(await readFile(path.join(dir, `${name}.json`), 'utf8'));
  const failures = [];
  for (const edit of edits) {
    try {
      applyEdit(bank, edit);
    } catch (error) {
      failures.push(error.message);
    }
  }
  if (failures.length > 0) throw new Error(`${failures.length} of ${edits.length} edits do not apply; nothing was written:\n${failures.join('\n')}`);
  const files = [...new Set(edits.map((e) => String(e.file).replace(/\.json$/, '')))];
  if (!dry) for (const name of files) await writeFile(path.join(dir, `${name}.json`), `${JSON.stringify(bank[name], null, 2)}\n`);
  return { applied: edits.length, files };
}

async function main(argv) {
  const { unit, args } = takeUnit(argv);
  const files = args.filter((a) => !a.startsWith('--'));
  if (unit === null || files.length !== 1) throw new Error('usage: node tools/apply-edits.js --unit <unit id> <edits.json> [--dry]');
  const [{ dir }] = await selectUnits(DATA_ROOT, unit);
  const edits = JSON.parse(await readFile(inUnit(dir, files[0]), 'utf8'));
  const result = await applyEdits(dir, edits, { dry: args.includes('--dry') });
  console.log(`${args.includes('--dry') ? 'Would apply' : 'Applied'} ${result.applied} edits to ${result.files.join(', ') || 'nothing'}.`);
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  main(process.argv.slice(2)).catch((error) => {
    console.error(error.message);
    process.exit(1);
  });
}
```
